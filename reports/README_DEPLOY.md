# Deployment Notes

This directory is a deployment-ready static site for Vercel.

- Deploy the project root (the folder containing `index.html` and `vercel.json`).
- Do not restore the removed `/guides/`, `/images/` or `/Product_picture/` folders unless there is a deliberate content/image-rights decision.
- Keep `vercel.json`, `robots.txt`, `sitemap.xml` and `scripts/site.js` with the deployment.
- After deployment, test the homepage, each category, several product pages and several old guide URLs.
- Then complete the Google Search Console actions in `reports/SEO_REPORT.md`.
